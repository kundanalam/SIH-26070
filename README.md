🌪️ CycloVision

AI-Driven Tropical Cyclone Intelligence Using Multi-Source Satellite Data

CycloVision is an AI/ML-based system for identifying, classifying, and analyzing tropical cyclone patterns using multi-source satellite imagery and meteorological data.

It combines satellite observations with parameters such as wind speed, sea surface temperature, atmospheric pressure, rainfall, location, and movement to provide a clearer understanding of cyclone behaviour.

🚀 Key Features

- Multi-source satellite image analysis
- Cyclone identification
- Cyclone type and intensity classification
- Meteorological parameter analysis
- Cyclone intensity trend visualization
- Movement and trajectory analysis
- Temporal analysis for future intensity trends
- Interactive web-based dashboard

🧠 Technology

- Python
- PyTorch
- ConvNeXt-Tiny – satellite image feature extraction
- GRU – temporal sequence analysis
- NumPy & Pandas – data processing
- NetCDF – satellite data
- HTML, CSS & JavaScript – web interface
- Kaggle – model training
- Vercel – prototype deployment
